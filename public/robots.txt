# WAYPOINT LEVER G1 - CRAWLER ACCESS.
#
# The failure this file exists to prevent is silent. A business that blocks an
# answering crawler does not get a warning, a ranking drop or a notification -
# it simply stops being available to name when somebody asks a model a
# question, and nothing anywhere says so. The default posture here is therefore
# ALLOW, explicitly, by name, for every agent that can put this business in an
# answer.
#
# Two different jobs are listed below and they are not the same thing:
#   ANSWERING / RETRIEVAL agents fetch a page live to answer a question that
#   was just asked. Blocking one removes this business from that answer today.
#   TRAINING agents read pages to build the model. Blocking one costs nothing
#   this week and costs eligibility in the next generation of models.
#
# Both are allowed deliberately. To opt out of training only, change the
# agents in the TRAINING block to Disallow and leave the answering block alone.
# Never blanket-Disallow: it reads as an opt-out of being findable at all.

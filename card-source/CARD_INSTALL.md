# The Card - install on highermindai.com

Derek's digital business card. The QR on his phone points at **https://highermindai.com/card** and
that address is permanent - never move or rename it.

## What goes where

| In this zip | Goes to | Published? |
|---|---|---|
| `card/index.html` | `<publish dir>/card/index.html` | yes |
| `card/derek-train.vcf` | `<publish dir>/card/derek-train.vcf` | yes |
| `card/og.jpg` | `<publish dir>/card/og.jpg` | yes |
| `netlify-headers.toml` | merge its two blocks into `netlify.toml` | - |
| `card-source/` | anywhere that is NOT served (the rebuild path) | no |
| `CARD_INSTALL.md` | not served | no |

## Steps

1. Read `netlify.toml` for the publish directory. Copy `card/` into it so the page serves at `/card/`.
2. Merge the two `[[headers]]` blocks from `netlify-headers.toml` into `netlify.toml`. The first makes
   the contact file open as a contact sheet on an iPhone; without it the Save button may download a
   text file instead.
3. `card/index.html` is self-contained (font, photo and QR are inline, no external requests). Change
   one thing only: add this site's own analytics tag to its `<head>`, the same one every other page
   carries. The page already pushes these events to `dataLayer`: `card_save`, `card_flip`,
   `card_share`, `card_finding` (channel: sms or whatsapp), `card_book`, `card_call`, `card_text`,
   `card_email`, `card_site`.
4. Keep `/card/` out of `sitemap.xml`. The page is `noindex` on purpose.
5. If the site is generated by a build script, make sure the script does not delete or overwrite
   `card/`. If the site's verify script checks for a single CTA or for unknown pages, allow `/card/`:
   it carries the contact save and the free-finding request, and ends on the nine minutes.
6. Push to the production branch.

- `https://highermindai.com/card/derek-train.vcf` returns `Content-Type: text/vcard`
- `https://highermindai.com/card/og.jpg` returns 200
- `card-source/` and this file return 404

## Rules already met - keep them if you edit

Solo first person. Hyphens only. No price anywhere. The letters "AI" appear in the wordmark only.
Every link to the site carries `utm_source=card&utm_medium=qr&utm_campaign=ladder-v6-general`
(the booking link inside the saved contact uses `utm_medium=contact`).

## Rebuild

`card-source/build.py` rebuilds the page and the contact file from `card.template.html` and
`CONTACT` at the top of the script. It needs `pip install segno` and the Montserrat variable woff2
(`npm install @fontsource-variable/montserrat`). `art.py` re-renders the QR artwork and `og.jpg`;
`verify.py` runs the checks. Change a phone number or email in `build.py`, never in the HTML.
